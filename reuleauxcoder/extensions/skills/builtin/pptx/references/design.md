# Design a usable deck

Start with the decision or understanding the audience should leave with. Give each slide a specific claim supported by relevant content. Use source-backed numbers and distinguish assumptions. A topic label alone rarely tells the audience enough.

Choose a restrained palette from the user's brand or subject, a compatible font family and a consistent spacing scale. Define these once in the generation script. Use contrast, alignment, whitespace and typography to establish hierarchy; decoration should support reading.

Match layout to content: a comparison can use aligned columns, a sequence a process diagram, a trend a chart, and a key result an emphasized figure with its interpretation. Vary layouts without changing the design language. Avoid turning every slide into the same grid of cards or bullets.

For a typical wide presentation, start around 30–40 pt for titles and 20–26 pt for body text, then validate at the intended viewing distance. These are starting points, not rules for every canvas. Split overloaded slides before shrinking all text. Leave room for translated or substituted fonts.

Charts need units, readable labels and honest scales. Prefer editable chart data when useful; use images for genuinely visual evidence. Explain key findings in the headline. Do not add a decorative chart without data.

Use fonts actually installed on the rendering host and likely available to the recipient. For CJK, check glyph coverage and specify East Asian fonts where required. Font family names alone do not embed fonts. A LibreOffice preview can differ from PowerPoint; disclose untested target applications.

Respect existing templates during edits. Redesigning a deck is a different scope from correcting text or updating a chart.
